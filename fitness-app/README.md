# Jeff's Fitness Coach

A simple Android-friendly web app with:
- large buttons
- spoken exercise instructions
- countdown timers
- ding sound between exercises
- Swimming Season and February plans

## Use it

Open `index.html` in a browser.

For phone use:
1. Serve the folder with any simple web server, or open the file directly.
2. In Android Chrome, use **Add to Home screen**.
3. Tap once before starting so speech/audio permissions are active.

## Notes

- Speech uses the browser's built-in text-to-speech voice.
- The beep uses the browser audio API.
- This is a first version and can be adjusted for exercise length, wording, or larger text.
